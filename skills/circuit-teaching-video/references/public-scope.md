# Public provenance and scope

This is a sanitized public adaptation of the owner's generic circuit-teaching skill 0.15.0 and later reusable production refinements. It is not the unchanged historical release and does not inherit historical lesson approvals or private review results.

## Preserved/generalized implementations

- Generic knowledge normalization, speech-notation helpers, mathematical typography checks, semantic decision/pointer audits, audio/frame/media helpers from the formal generic skill.
- Actual production native-density formula paint/reveal methods, ink-front pointer geometry, semantic variable coloring, world camera, cumulative objects and frame receipts.
- Production safe-zone layout, real font-role measurement, internal caption strip and exact-white attention-underlay protection, generalized to portable font configuration.
- Source-PDF catalog rasterization and explicit optional speech/cache/provider sentence-receipt adapter, with project-relative inputs instead of private lesson paths.

## Public additions and deliberate scope decisions

- One portable compiler/CLI for the supported public world-canvas subset, frozen runtime/font hashes and exact frame/decode checks.
- Complete formal-manuscript caption references, separately derived source-span speech adaptation and explicit formal/speech/voice/audio/timing identity binding. Text coverage is structural evidence, not a semantic or listening certification.
- An original resistor-divider example and isolated regression tests. No course content was translated into a supposedly original example.
- Dependencies are installed separately. No font binaries, third-party package source, historical private approval records or credentials are included.
- Omitted: lecture-specific source catalogs, lesson scripts, source PDFs, original figures, recordings, videos, private review screenshots, prior release archives and user history.
- The default five-node route adds single-master source organization, explicit native authoring, full-caption/phonetic derivation, validated real sentence-evidence adaptation, rendering and local cache-aware rework. Bounded private real-production checks informed it; their materials and approvals are not bundled or inherited by new projects.
- Not claimed: a byte-identical historical release, universally automatic authoring/layout, arbitrary provider chunking, all scanned/complex PDFs, arbitrary image matte safety, word alignment, full-course scientific certification or learning outcomes.

The code labeled as extracted originated within the owner's supplied project. No license header from a separately identified third-party source was removed. Package/font dependencies remain independently licensed. This inspection cannot prove that every historical input had perfect provenance; reports of attribution or rights issues should be investigated before redistribution.
